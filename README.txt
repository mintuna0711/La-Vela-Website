LA VELA CHRISTMAS WEBSITE

Cau truc file:
- index.html: khung noi dung website
- style.css: giao dien, mau sac, font, responsive desktop/mobile
- script.js: chuc nang chon set, tinh tong tien, form demo va trang cam on

Cach mo trong VS Code:
1. Giai nen thu muc la_vela_website_source.zip.
2. Trong VS Code, chon File > Open Folder va mo thu muc nay.
3. Mo index.html de xem/chinh sua.
4. Nen cai extension Live Server, sau do click chuot phai index.html > Open with Live Server.
5. Khi cap nhat website GitHub Pages, commit va push ca 3 file.

Luu y: Form dat banh hien la demo, chua gui du lieu den khach san. Cac anh san pham co the dung URL anh truc tuyen nhu trong code.
